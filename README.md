One funny single-line one-star review from a house cat about its human, written to
`/output/entry.txt` by `main.ts` (Node 22, standard library only, no network).
The output is deterministic: the same single line every run, written with no
trailing newline, and the program throws if the line ever exceeds 200 characters.

Entry (152 characters, limit 200):

> One star. He shoves me off his warm laptop to type 'urgent' emails, then acts shocked when I sit on the keyboard and email his boss a row of kkkkkkkkkk.

Run it:

```sh
node main.ts
```
